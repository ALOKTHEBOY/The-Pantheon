# 🏛️ The Pantheon (formerly NovaCart Pro)

A high-performance, premium e-commerce Single Page Application (SPA) built entirely with Vanilla JavaScript, Vite, and Firebase. 

## 🚀 Key Architectural Features
*   **Custom CMS (Content Management System):** An admin dashboard that writes directly to Firestore, allowing real-time curation of the 3-Tier Homepage layout.
*   **Interactive Sound Engine:** A custom global state manager that triggers tactile UI sound effects for cart actions and notifications, with user-controlled mute preferences.
*   **Glassmorphism UI:** A fully responsive, premium aesthetic utilizing CSS variables, sticky frosted-glass headers, and dynamic gradients.
*   **Smart Routing:** Parameter-based URL routing for dynamic filtering straight from the homepage hero banners.
*   **Real-time Database:** Powered by Firebase Firestore for instantaneous product loading, cart state, and order history syncing.

## 🛠️ Tech Stack
*   **Frontend:** Vanilla JavaScript (ES6+), HTML5, Custom CSS3 Variables
*   **Backend/Auth:** Firebase Authentication, Cloud Firestore
*   **Build Tool:** Vite
*   **Hosting:** Firebase Hosting
