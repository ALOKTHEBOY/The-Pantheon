# 🛒 NovaCart Pro

A premium, Single Page Application (SPA) E-commerce platform built with clean Vanilla JavaScript and Google Firebase[cite: 5].

A high-performance, responsive e-commerce Single Page Application (SPA) built strictly with Vanilla JavaScript and Firebase[cite: 5]. No frontend frameworks—just clean architecture, state management, and modern DOM manipulation[cite: 5].

[View Live Project](https://novacart-pro.netlify.app/)[cite: 5]

## ✨ Key Features
*   **Modular Vanilla JS SPA:** Custom client-side hash routing system featuring domain-driven sub-routing without external router libraries[cite: 5].
*   **Global State Management:** Custom reactive stores for Cart, Wishlist, and Notifications[cite: 5].
*   **Firebase Authentication:** Secure email/password login, registration, password reset, session management, and protected routing[cite: 5].
*   **Dynamic Catalog:** Real-time product fetching from Firestore with advanced search, category filtering, and multi-parameter sorting[cite: 5].
*   **Shopping Cart:** Global state management for cart items, calculating totals, and a seamless checkout flow[cite: 5].
*   **Secure Admin Dashboard:** Role-based access control (RBAC) protecting a full CRUD interface connected to Firebase Firestore for real-time inventory management[cite: 5]. Features a dynamic discount calculator and dual-media upload methods (URL or Base64 files)[cite: 5].
*   **Event Delegation:** Highly optimized global click listeners for DOM interactions[cite: 5].
*   **Persistent & Responsive UI:** Native CSS variables for Dark/Light mode and local storage data persistence[cite: 5]. CSS Grid/Flexbox architecture with a modern, polished aesthetic, including animated hover states, discount badges, and collapsible text blocks[cite: 5].

## 🛠️ Tech Stack
*   **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Properties)[cite: 5]
*   **Backend/Database:** Google Firebase (Authentication, Firestore)[cite: 5]
*   **Architecture:** Domain-Driven Design, Hash-based SPA Routing, Custom State Management (Store Pattern)[cite: 5]
*   **Build Tool:** Vite[cite: 5]
*   **Deployment:** Netlify CI/CD[cite: 5]
