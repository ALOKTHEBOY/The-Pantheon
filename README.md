# 🛒 NovaCart Pro

A high-performance, responsive e-commerce Single Page Application (SPA) built strictly with Vanilla JavaScript and Firebase. No frontend frameworks—just clean architecture, state management, and modern DOM manipulation.

## 🚀 Live Demo
[View Live Project](https://novacart-pro.netlify.app/)

## ✨ Key Features
*   **Vanilla JS SPA:** Custom client-side hash routing system without external router libraries.
*   **Global State Management:** Custom reactive stores for Cart, Wishlist, and Notifications.
*   **Firebase Authentication:** Secure email/password login, session management, and protected routing.
*   **Event Delegation:** Highly optimized global click listeners for DOM interactions.
*   **Persistent UI:** Native CSS variables for Dark/Light mode and local storage data persistence.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3, ES6+ JavaScript
*   **Backend/Auth:** Google Firebase
*   **Build Tool:** Vite
*   **Deployment:** Netlify CI/CD
