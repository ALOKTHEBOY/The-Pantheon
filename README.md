# 🛒 NovaCart Pro

A premium, Single Page Application (SPA) E-commerce platform built with clean Vanilla JavaScript and Google Firebase.

A high-performance, responsive e-commerce Single Page Application (SPA) built strictly with Vanilla JavaScript and Firebase. No frontend frameworks—just clean architecture, state management, and modern DOM manipulation.

## 🚀 Live Demo
[View Live Project](https://novacart-pro.netlify.app/)

## ✨ Key Features
*   **Vanilla JS SPA:** Custom client-side hash routing system without external router libraries.
*   **Global State Management:** Custom reactive stores for Cart, Wishlist, and Notifications.
*   **Firebase Authentication:** Secure email/password login, session management, and protected routing.
*   **Event Delegation:** Highly optimized global click listeners for DOM interactions.
*   **Persistent UI:** Native CSS variables for Dark/Light mode and local storage data persistence.
*   **Secure Admin Dashboard:** Role-based access control (RBAC) protecting a full CRUD interface connected to Firebase Firestore for real-time inventory management.

## ✨ Features
*   **Authentication:** Firebase Email/Password login, registration, password reset, and profile management.
*   **Dynamic Catalog:** Real-time product fetching from Firestore with advanced search, category filtering, and multi-parameter sorting.
*   **Shopping Cart:** Global state management for cart items, calculating totals, and a seamless checkout flow.
*   **Admin Dashboard:** Secure, role-based access control (RBAC) for store managers. Features full CRUD capabilities, a dynamic discount calculator, and dual-media upload methods (URL or Base64 files).
*   **Responsive UI:** CSS Grid/Flexbox architecture with a modern, polished aesthetic, including animated hover states, discount badges, and collapsible text blocks.

## 🛠️ Tech Stack
*   **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Properties)
*   **Backend/Database:** Google Firebase (Authentication, Firestore)
*   **Architecture:** Hash-based SPA Routing, Custom State Management (Store Pattern)
*   **Backend/Auth:** Google Firebase
*   **Build Tool:** Vite
*   **Deployment:** Netlify CI/CD
